# PLACE MAKING WITH UDC — Online Flipbook

GitHub Pages-ready static website generated from the updated 2026-08-26 PDF.

## Features
- Dark gray presentation background
- Original 2:1 spread ratio preserved
- High-resolution lossless PNG page images (220 DPI)
- Desktop: full-spread viewing
- Mobile portrait: single square page viewing
- Mobile landscape: full spread viewing
- Touch swipe, arrow keys, wheel-friendly navigation
- Thumbnail navigation and fullscreen
- CSS 3D page-turn animation with the turning sheet anchored at the lower-right corner for the forward turn

## GitHub Pages
1. Create a public repository.
2. Put `index.html`, `style.css`, `script.js` and the `pages` folder in the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save and wait for the Pages deployment.

## Navigation adjustment
- The left/right page-turn animation directions have been swapped; navigation controls and page order remain unchanged.
